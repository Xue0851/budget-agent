# 赛博节俭局 —— 消费决策 Agent

基于多角色协作与约束优化的大学生消费决策助手。输入想买的商品、预算和个人需求，由「欲望、理性、优惠、裁判」四个角色基于同一组事实提出观点，最终给出可追溯的购买建议和经过程序验证的优惠方案。

## 预算业务规则（方案 2.1 节）

所有金额使用整数「分」，界面显示「元」。

```text
基本支出 = 剩余天数 × 每日基本开支 + 剩余固定支出
可自由支配预算 = 当前现金 - 基本支出 - 预留金
购买后现金 = 当前现金 - 方案实际支付金额
预算通过 = 购买后现金 >= 基本支出 + 预留金
```

关键约定：
- 可自由支配预算为负时如实显示，不截断为 0。
- 缺失的关键字段写入 `missing_fields`，不得默认当作 0。
- 优惠不能让预算不通过的方案绕过检查。
